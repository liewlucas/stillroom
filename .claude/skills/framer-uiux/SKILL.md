# Framer UIUX Designer

## Purpose

Use this skill together with ui-ux-pro-max when the user asks for website, landing page, portfolio, SaaS page, dashboard, or marketing page design intended to be built in Framer.

The user has no Framer experience, so every design should be explained as beginner-friendly Framer build instructions.

## Instructions

When designing for Framer, do not only describe the visual concept. Output a practical Framer build plan.

For every design, include:

1. Page objective
- Who the page is for
- What the page should communicate
- What action the visitor should take

2. Page structure
- List sections from top to bottom
- Give every section a clear Framer-friendly name
- Explain what each section contains

3. Framer layer structure
For each section, specify:
- Frame name
- Whether it uses vertical stack, horizontal stack, or grid
- Width behavior: fill, fixed, or max-width
- Suggested max-width
- Padding
- Gap
- Alignment
- Text layers
- Image layers
- Button layers
- Card layers
- Components

4. Visual system
Include:
- Font suggestions
- Desktop and mobile type scale
- Color styles
- Button styles
- Card styles
- Border radius
- Shadows
- Spacing scale

5. Responsive behavior
Explain how each major section should adapt for:
- Desktop
- Tablet
- Mobile

6. Reusable components
Identify components such as:
- NavBar
- Button
- SectionHeader
- FeatureCard
- TestimonialCard
- PricingCard
- FAQItem
- Footer

7. Interactions
Prefer simple Framer-native interactions:
- Hover states
- Scroll reveal
- Sticky nav
- FAQ accordion
- Button hover animation

8. Code components
Avoid code components unless Framer native tools are not enough.
If code is required, explain why and provide beginner-friendly Framer-compatible React code.

9. Build checklist
End with a step-by-step checklist the user can follow inside Framer.
